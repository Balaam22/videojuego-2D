# 👻 Caza de Fantasmas - Videojuego 2D

Proyecto final desarrollado para la materia de **Graficación** en el **Instituto Tecnológico de Pachuca (ITP)**.

## 📌 Descripción del Proyecto
Aplicación web interactiva desarrollada en **HTML5 Canvas, JavaScript y Bootstrap**, que simula un entorno de caza de fantasmas bidimensional con múltiples patrones de movimiento, procesamiento dinámico de imágenes para transparencia, efectos de colisión con rebote físico y audio ambiental.

## 🛠️ Tecnologías y Herramientas Utilizadas
* **HTML5 Canvas & JavaScript (ES6+):** Lógica del motor de juego, bucle de animación (`requestAnimationFrame`), gestión de clases (`Ghost`), y renderizado gráfico.
* **CSS3 & Bootstrap 5:** Estilos responsivos, barra de navegación, panel de control y cursor personalizado interactivo (`🎃`).
* **Git y GitHub Pages:** Control de versiones y despliegue en la nube.

## 📝 Conclusiones
* **Desarrollo Gráfico:** El uso de HTML5 Canvas combinado con programación orientada a objetos permitió gestionar de manera eficiente el renderizado y las coordenadas de múltiples entidades independientes simultáneamente.
* **Optimización y Multimedia:** La implementación de funciones en JavaScript para el procesamiento en tiempo real de canales de píxeles (`getImageData`) resolvió de forma óptima los problemas de transparencias en los recursos gráficos sin comprometer el rendimiento.
* **Experiencia de Usuario (UI/UX):** La integración de elementos multimedia, cursores personalizados basados en SVG y diseño responsivo con Bootstrap mejoraron notablemente la presentación visual y la interactividad del videojuego.
